# モバイルICOCA 利用明細 CSV出力

モバイルICOCA会員メニューサイトの利用明細（履歴印刷）画面に **「CSV出力」ボタン** を追加する Chrome 拡張です。
「表示された履歴を印刷」ボタンの横に並び、押すと画面に表示されている明細がそのまま CSV でダウンロードされます。

**処理はすべてブラウザ内で完結します。** 明細データを外部サーバーへ送信することはありません
（拡張から外部への通信コードは一切なく、ネットワーク権限も要求していません）。

## インストール

1. このリポジトリを手元に clone またはダウンロードする
2. Chrome で `chrome://extensions/` を開く
3. 右上の **デベロッパーモード** をオンにする
4. **「パッケージ化されていない拡張機能を読み込む」** を押し、このフォルダ（`manifest.json` がある階層）を選ぶ

## 使い方

会員メニューにログインし、利用明細の画面を開くと「表示された履歴を印刷」の横に「CSV出力」ボタンが表示されます。
押すとその場で CSV がダウンロードされ、画面下部に「◯件の明細をCSVに出力しました。」と表示されます。

ボタンが出ない場合は、ツールバーの拡張機能アイコン（青い下向き矢印）を押してください。
`manifest.json` の `matches` に載っていないホストでも、その場かぎりの権限（`activeTab`）でCSV出力を実行します。

### 対象サイトのホストが違う場合

会員メニューのホスト名は `manifest.json` の `content_scripts[0].matches` に列挙しています。
ご利用のURLがここに無い場合は、アドレスバーのホスト名を次のように追記すると自動でボタンが出るようになります。

```jsonc
"matches": [
  "*://*.jr-odekake.net/*",
  "*://実際のホスト名/*"   // ← 追記
]
```

追記後は `chrome://extensions/` で拡張機能の再読み込み（更新ボタン）が必要です。

## 出力される CSV

- 文字コード: UTF-8（BOM 付き。Excel でそのまま開けます）
- 改行: CRLF
- 列:

| 列 | 内容 |
| --- | --- |
| 日付 | `YYYY-MM-DD`。後述のとおり年を補完した値 |
| 月/日 | 画面に表示されているままの月日 |
| 種別1 / 利用場所1 | 表の左側の「種別」「利用場所」（入場駅など） |
| 種別2 / 利用場所2 | 表の右側の「種別」「利用場所」（出場駅など） |
| 残額 | `¥` とカンマを外した数値 |
| 差額 | 符号付きの数値。最古の行は明細に表示されないため空欄 |

ファイル名は `icoca_meisai_20260327-20260727.csv` のように、明細の期間が入ります。

### 年の補完について

明細の表には月日しか印字されていないため、**実行日を基準に古い方へ遡って年を復元** しています。
表は新しい順に並び、表示範囲は最大26週なので、直前の行より日付が新しくなった時点で年をひとつ戻す、という方法で一意に決まります。
元の表記は「月/日」列にそのまま残しているので、補完結果は照合できます。

## 権限

| 権限 | 用途 |
| --- | --- |
| `activeTab` | ツールバーアイコンを押したタブにだけ、その場でスクリプトを流し込むため |
| `scripting` | 上記の実行に必要 |
| `content_scripts` の `matches` | 会員メニューのページを開いたときにボタンを追加するため |

ダウンロードは `Blob` と `<a download>` で行っており、`downloads` 権限も使っていません。

## 開発

```sh
npm test        # 解析・CSV生成のユニットテスト（Node 標準テストランナー、依存なし）
npm run test:e2e   # 実ブラウザでの動作確認（Playwright が必要）
```

- `src/parser.js` — 表の解析と CSV 生成。DOM に依存しない純粋関数と薄い DOM 層に分けてある
- `src/content.js` — ボタンの設置、ダウンロード、トースト表示
- `src/background.js` — ツールバーアイコンからの実行
- `test/fixtures/meisai.html` — 実画面と同じ構造のテスト用ページ（データはダミー）

## 制限

- 画面に表示されている明細（最新100件、最大26週分）が対象です。過去分をまとめて取得する機能はありません。
- 「利用場所」は改札機の表示と同じ4文字程度の略称のまま出力します。
